# Visiting

**UC-01 See the scene.** Steps: open the site in a desktop window. Expected: one picture fills the window with one creature at its centre; the page does not scroll sideways; the browser tab title names the owner.

**UC-02 Find the five projects.** Steps: reach each arm in turn. Expected: five arms carry a project, one each; the five project names match the content sheet, and none appears twice.

**UC-03 Read a logline.** Steps: reach a project's arm. Expected: the project's name and logline can be read, word for word as in the content sheet; the logline is 25 words or fewer; the words stay readable for as long as the arm is reached.

**UC-04 Open a live site.** Steps: reach a project's arm; follow its live site link. Expected: the same tab goes to that project's live site address from the content sheet; the browser's Back button returns to the scene.

**UC-05 Open a repository.** Steps: reach each project's arm and look for a repository link; follow each one found. Expected: each project with a repository in the content sheet offers a repository link that goes to that address; each project marked "none (private)" offers no repository link.

**UC-06 Meet the owner.** Steps: look over the scene; follow the GitHub link. Expected: the owner's name and bio can be read inside the picture, word for word as in the content sheet; the profile link goes to its address from the content sheet.

**UC-07 Open an unknown address.** Steps: open the site with any extra path, such as `/squid`. Expected: the scene appears, the same as at the root address.

**UC-08 Arrive by the other domains.** Steps: open `pumblechook.dev`; open `pumblechook.dev/anything`; open `www.pumblechook.com`. Expected: each lands on `https://pumblechook.com` and shows the scene.
